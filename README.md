# Shopping Cart Hook Challenge

A Rocketseat Ignite challenge focused on implementing shopping-cart behavior with React hooks.

## Project goal

Complete an existing storefront interface by building the cart state, quantity rules, persistence and user feedback expected by the provided test suite.

## Features

- Add and remove products
- Increase and decrease quantities
- Persist the cart locally
- Calculate product subtotals
- Display success and error feedback

## Technologies

- **TypeScript**
- **React**
- **React Hooks**
- **Axios**
- **Styled Components**
- **JSON Server**
- **Jest**

## What I learned

- Encapsulating shared state in a custom hook
- Keeping derived totals consistent with cart state
- Persisting client state
- Implementing behavior against automated tests

## Running locally

```bash
npm install
npm run server
# In another terminal:
npm start
```

## Project status

This is a learning project and is not presented as a production-ready application.
